# Автозагрузка объявлений на Авито

Публичный репозиторий генерирует XML-ленту Авито из `data/items.json` и публикует её через GitHub Pages.

## Ссылки

- XML для Авито: `https://anastasiaebral-hue.github.io/avito-autoload-feed/avito.xml`
- Страница проверки: `https://anastasiaebral-hue.github.io/avito-autoload-feed/`

## Безопасный порядок работы

1. Новые объявления добавляются в `data/items.json` с `"enabled": false`.
2. Добавляются фотографии в `public/images/` и прямые ссылки на них в `images`.
3. Поля категории сверяются с актуальным шаблоном Авито.
4. После подтверждения владельца объявления ставится `"enabled": true`.
5. Генератор создаёт `public/avito.xml`, тесты проверяют структуру, GitHub Pages публикует файл.

Не добавляйте в репозиторий пароли, API-ключи, cookies, номер телефона или точный домашний адрес. Репозиторий и XML публичные.

## Локальная проверка

```bash
python -m unittest discover -s tests -v
python generate_feed.py
python -c "import xml.etree.ElementTree as ET; ET.parse('public/avito.xml'); print('XML OK')"
```

## Связка с существующим объявлением

Для уже опубликованного объявления укажите поле `avito_id`. Генератор добавит элемент `<AvitoId>`, чтобы Авито связал запись из XML с существующим объявлением и не создавал дубликат.

## Важно

Оба начальных объявления сохранены как черновики (`enabled: false`). Они не попадут в XML, пока не будут добавлены подходящие фотографии, обязательные параметры категории и явное подтверждение публикации.
